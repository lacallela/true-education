# 🎓 Истинное образование (Пусть послужит вам уроком) | 참교육
### Официальный интерактивный фан-портал дорамы и вебтуна (ERPB Fan Portal)

> **«Когда закон бессилен, а страх парализует школы — в дело вступает Бюро по защите прав учителей. Уроки вежливости начинаются прямо сейчас.»**

Портал создан для поклонников культовой корейской франшизы **«Истинное образование»** (*참교육*, *Teach You a Lesson* / *Get Schooled*), объединяющей всемирно популярный вебтун Naver/YLAB от авторов Чхэ Ён Тэка и Хан Га Рама и флагманскую экшен-дораму Netflix от режиссера Хон Джон-чхана (*«Ювенальный суд»*).

## ⚡ Функционал и разделы сайта

1. **Главный экран (Hero Section)**:
   - Кинематографичный баннер инспектора На Хваджина в школьном коридоре.
   - Бейджи наград, рейтинг IMDb 8.9 / Kinopoisk 8.8, Топ-1 Netflix Non-English.
   - Модальный видеоплеер официального тизер-трейлера дорамы.
   - Ключевая статистика (10 серий, 100% раскрываемость дел, вселенная Super String).
2. **Вселенная и концепция (About Drama)**:
   - Предыстория создания Бюро по защите прав учителей (ERPB) при Министерстве образования Республики Корея.
   - 4 незыблемых столпа дисциплинарной философии На Хваджина.
   - Интерактивное сравнение: **Дорама Netflix** vs **Вебтун Naver (YLAB)** с переключением вкладок.
3. **Личные досье инспекторов (Interactive Dossiers)**:
   - **На Хваджин (Ким Му Ёль)** — главный полевой инспектор с деревянной тростью (Level 4).
   - **Им Ханрим (Джин Ки Джу)** — штурмовой эксперт и чемпионка по тхэквондо (Level 3).
   - **Пон Гын Дэ (Пё Джи Хун / P.O)** — гений кибер-разведки и координатор операций.
   - **Чхве Ган Сок (Ли Сон Мин)** — Министр образования Республики Корея, основатель агентства.
   - Индикаторы ТТХ (боевая мощь, тактика, устрашение, психология, авторитет), коронные цитаты, позывные и различия с вебтуном.
4. **Гид по 10 сериям (Episodes Guide)**:
   - Подробная сводка каждого из 10 эпизодов 1-го сезона.
   - Фильтрация по тематикам: школьный буллинг, криминальные синдикаты, коррупция элиты, лор и прошлое.
   - Главные дисциплинарные уроки и модальные окна с материалами каждого расследования.
5. **Архив дел и вещдоков (Cases Archive Terminal)**:
   - Интерактивный терминал следственного отдела: Дело школы Мунъян, Золотой клуб Чондам, Нелегальный октагон, Экзаменационный синдикат.
   - Аудиозаписи угроз, вещественные доказательства, протоколы допросов.
   - Интерактивное действие: **«Поставить гербовую печать Бюро»** с сочным звуковым эффектом штампа!
6. **Аттестационный тест инспектора (Interactive Quiz)**:
   - 5 реальных ситуационных задач школьных конфликтов.
   - Определение квалификационного профиля.
   - Генерация **цифрового удостоверения инспектора ERPB** с вашим именем, серийным номером, голографическим гербом, праздничным салютом конфетти и кнопкой копирования удостоверения!
7. **Кодекс и цитатник На Хваджина (Quotes Generator)**:
   - Генератор уроков и жестких афоризмов На Хваджина, Им Ханрим и Министра Чхве с кнопкой копирования в буфер обмена.
8. **Медиагалерея (Poster & Still Gallery)**:
   - Полноэкранный Lightbox-просмотрщик промо-постеров, артов манхвы, штаб-квартиры ERPB и кадров экшен-сцен с возможностью скачивания.
9. **Фан-зона (Community & Theories)**:
   - Обсуждение теорий ко 2 сезону и пасхалок к мультивселенной Super String.
   - Форма добавления собственного отзыва и оценки (сохраняется в `localStorage`).
10. **Аудио-движок Web Audio API**:
    - Интегрированные тактические звуковые эффекты (удары трости, постановка печати, подтверждение доступа, терминальные клики).

## 💻 Локальный запуск и разработка

```bash
# 1. Клонировать или перейти в папку проекта
cd D:\dorama_site

# 2. Установить зависимости (если еще не установлены)
npm install

# 3. Запустить локальный сервер для разработки
npm run dev

# 4. Собрать оптимизированный production-билд
npm run build

# 5. Предпросмотр production-сборки локально
npm run preview
```

Сборка компилируется в папку `dist/` менее чем за 1 секунду.

## 🚀 Инструкция по деплою (Подготовлено «из коробки»)

Проект полностью настроен для деплоя на любую современную платформу без дополнительной настройки.

### Вариант 1: Деплой на Vercel (Рекомендуется, 1 минута)
В корне проекта уже создан файл `vercel.json`.
1. Установите Vercel CLI (при желании): `npm i -g vercel`
2. Выполните команду `vercel` в папке проекта, либо:
3. Загрузите проект в репозиторий GitHub/GitLab и импортируйте его на [vercel.com](https://vercel.com):
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. Нажмите **Deploy** — проект мгновенно опубликован с бесплатным SSL-сертификатом и CDN!

### Вариант 2: Деплой на Netlify
В проекте уже настроены `netlify.toml` и `public/_redirects`.
- **Способ А (Drag-and-Drop без Git)**:
  1. Выполните `npm run build`.
  2. Перейдите на [app.netlify.com/drop](https://app.netlify.com/drop).
  3. Перетащите папку `dist` прямо в окно браузера — сайт будет онлайн через 10 секунд!
- **Способ Б (Через Git)**:
  1. Подключите репозиторий в панели Netlify.
  2. Параметры определятся автоматически из `netlify.toml`.

### Вариант 3: Деплой на GitHub Pages
В проекте настроен автоматический CI/CD GitHub Action: `.github/workflows/deploy.yml`.
1. Создайте репозиторий на GitHub и отправьте код:
   ```bash
   git init
   git add .
   git commit -m "feat: True Education fan portal ready for deploy"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/true-education-fan.git
   git push -u origin main
   ```
2. В репозитории откройте **Settings** → **Pages** → в выпадающем списке **Source** выберите **GitHub Actions**.
3. При каждом пуше в ветку `main` сайт автоматически пересоберется и опубликуется на `https://ВАШ_ЛОГИН.github.io/true-education-fan/`.

### Вариант 4: Деплой в Docker (VPS / Cloud / Render / Fly.io)
В проекте подготовлены многоэтапный `Dockerfile` на базе легкого Alpine Linux и оптимизированный `nginx.conf` со сжатием Gzip и кэшированием статики.

```bash
# Сборка Docker-образа
docker build -t true-education-fan .

# Запуск контейнера на 80 порту
docker run -d -p 80:80 --name erpb-portal true-education-fan
```
Теперь сайт доступен по адресу `http://localhost` или по IP-адресу вашего сервера.
